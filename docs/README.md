# Documentation

- `STATUS.md` describes the current public-release position, known missing systems, and roadmap.
- `RELEASE-HYGIENE.md` lists source-only publishing checks and history-cleanup rules.
- `REFERENCE.md` records detailed runtime/importer findings and implementation notes.
- `PHYSICS.md` summarizes the current player-physics bridge and known approximations.
- `PHYSICS-REFERENCE.md` captures native-unit physics notes and future work.
- `PLAN.md` keeps the high-level implementation plan.

For a public release, `STATUS.md` and `RELEASE-HYGIENE.md` are the most important documents to keep accurate.
